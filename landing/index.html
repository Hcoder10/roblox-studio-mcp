Multi-Agent Orchestration

An orchestrator decomposes requests into tasks, assigns them to specialized team leads (Building, Scripting, Visual), who execute sequentially with exclusive resource locks to prevent conflicts.

118 MCP Tools

Full Roblox Studio control: instance creation, script management, terrain editing, playtesting, animation, diagnostics, UI building, cloud APIs, and Luau parsing — all via Model Context Protocol.

Deep Thinking Mode

Gemini 3.1 Pro with 32K thinking budget generates production-quality Luau scripts with proper game mechanics, OOP patterns, and server-client architecture.

RAG Knowledge Base

1,272 chunks from the Roblox API dump + 28 expert pattern documents give agents deep knowledge of every Instance class, service, and best practice.

Resource Locking

Hierarchical path locks + category locks prevent agents from overwriting each other. Building agent locks Workspace.Map while Scripting locks ServerScriptService — zero conflicts.

Real-Time UI

WebSocket-powered dashboard shows live agent status, task progress, tool calls, lock visualization, and chat — all updating in real-time as agents work.

Quick Start

1 Clone the repo: git clone https://github.com/SquaredCub/roblox-studio-mcp.git
2 Install deps: npm install && npm run build
3 Copy packages/plugin/StudioBridgeMCP.rbxmx to %LOCALAPPDATA%\Roblox\Plugins\
4 Start MCP server: cd packages/server && node dist/index.js
5 Set GEMINI_API_KEY in packages/agent-harness/.env
6 Start agent harness: cd packages/agent-harness && node dist/index.js
7 Open Roblox Studio → click Connect in the plugin toolbar
8 Open http://localhost:5173 for the Agent UI and start building!
